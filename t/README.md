# Short translation links

`innovativeassessmentsolutions.com/t/<code>` forwards to
`report-translations/translation-<code>.pdf`. These are the short, typable addresses printed on the
Astra parent report (p.2). GitHub Pages has no server-side redirects, so each `t/<code>/index.html`
forwards with a meta refresh plus JavaScript, and shows a plain link as a fallback. Like the PDFs,
they are unlinked from the site and marked `noindex`.

  es  Spanish   sw  Swahili   rw  Kinyarwanda   ne  Nepali   my  Burmese   ksw  S'gaw Karen

Adding a language: add `report-translations/translation-<code>.pdf` and a matching `t/<code>/index.html`.
