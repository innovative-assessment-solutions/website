# Parent report translation companion sheets

Per-language PDF companions to the Astra Student Progress Report. They translate
only the report's FIXED framing text (headings, labels, explanations). They are
served by direct URL and are intentionally NOT linked from any page or the
navbar — families reach them from the QR code / link printed in their student's
report.

  report-translations/translation-<code>.pdf

  es  Spanish        sw  Swahili       rw  Kinyarwanda
  ne  Nepali         my  Burmese       ksw S'gaw Karen

Drafts pending district-translator review (see the banner on each sheet).
Regenerate with 3_Processes/3.3_Reporting/html-prototype/build-translation-sheets.mjs
in the Astra Pipeline repo.
